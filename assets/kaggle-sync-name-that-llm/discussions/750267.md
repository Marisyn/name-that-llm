Hi, fellow competitors!

Inspired by comments about this competition being "pay to win" and being particularly data-hungry (friendly reminder that [Kaggle competition TOS](https://www.kaggle.com/competitions/name-that-llm/rules) prohibit using data that is not public and freely usable by all competitors), I have decided to put my free Claude API credits and whatever little credits I had on Openrouter to good use. Above is a dataset that I plan on updating from time to time, i.e. when my AI quotas on kaggle reset. I implore everybody participating to make good use of the monthly 100$ worth of credits for this competition - at the end of the day, we can gather a large portion of high-quality, matched data for this competition together :)

I would make an effort to make a high-quality pipeline for this dataset, or to expand this database into a truly massive one, but I am currently working very hard on college apps, so that will have to wait. For now, this is all that I can contribute; I advise everybody that has some leftover or free promotional credits to create similar databases for everybody to use.

Happy Kaggling!
