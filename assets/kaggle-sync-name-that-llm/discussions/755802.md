Model Approach – Name That LLM

This solution uses a traditional machine learning approach combining:

Character-level TF-IDF features (2–5 n-grams).

Word-level TF-IDF features (1–3 n-grams).

Text style and statistical features.

Linear Support Vector Classification (LinearSVC).

The extracted features are combined into a single feature matrix and used to train the classifier to identify the LLM responsible for each text passage.
