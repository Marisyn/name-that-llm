## Content

Hi everyone,

I recently joined *Name That LLM* as my very first Kaggle competition[cite: 1, 4]! Coming in with limited hands-on model training experience, I wanted to document my progress and share a few questions with the community.

My Progress So Far:
1. Initial Baseline: Built a basic TF-IDF + Logistic Regression pipeline, scoring **0.322** on 5-fold GroupKFold cross-validation and the public leaderboard. 
2. GPU Acceleration & Ensemble: Enabled GPU T4 x2 acceleration[cite: 6, 8] and executed the public *LoRA + Adaptive Centering ensemble (credits to Vladislav Lavrentev & Lucas Boesen), which brought my score to 0.541 .
3. Pipeline Integration: Set up inter-notebook output mounting to pass TF-IDF class probabilities (`tfidf_probs.csv`) directly into downstream GPU ensemble runs for hybrid probability blending experiments.

Questions for Experienced Competitors:
1. When ensembling linear TF-IDF probability outputs with fine-tuned deep Transformer readouts, do you recommend applying temperature scaling or rank averaging before blending to prevent high-confidence deep learning predictions from dominating?
2. How do you balance character $n$-gram stylometric features alongside contextual embeddings without overfitting the public leaderboard?

Excited to keep learning from this community! Any feedback or tips for a newcomer would be greatly appreciated.

In Lavrentev's notebook, there are sayed "under genre shift (external data) predictions collapsed onto one class and balancing took balanced accuracy from 0.12 to 0.1". So data balance is very important here. You can try to balance data, for example, balance datasets or genres. Also you can try data augmentation. Or you can try tune batch_size and learning_rate. If dataset is small and main problem is overfitting - decrease batch_size or increase learning_rate. If dataset is big and complex, and model size is small (main problem is underfitting) - increase batch_size or decrease learning_rate
