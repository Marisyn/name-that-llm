## Content

Has anyone experienced unusually slow file loading from /kaggle/input on certain Kaggle GPU sessions?
Code Competition, GPU enabled, internet disabled. The same notebook and attached datasets have worked normally in previous runs, but a recent T4 session showed dramatically slower loading times:

A file of a few hundred MB took approximately 16 minutes to load.

A separate multi-GB loading operation has been running for over 3 hours.

GPU computations outside the loading stages appear to run at normal speed.

This makes me suspect an intermittent dataset storage or I/O performance issue, although I haven't independently benchmarked the mount's read throughput.

A few questions:

Has anyone experienced similar behavior? Could this be related to certain nodes or temporary storage performance issues?

Can this also happen during hidden reruns of Code Competition submissions, potentially causing timeouts?

Are there any recommended mitigations, such as early read-speed checks, changing file packaging, or retrying on a different session?

Any experiences, benchmarks, or official guidance would be greatly appreciated.
