I added a 10% ATLAS blend to Maman Salto’s Apex v4 and got 0.558 on the public leaderboard, up from the original 0.556. The ATLAS adapter uses Qwen3-8B-Base and was trained on the official 2,699 training rows. Its probabilities are mixed in before the original balancing, with the rest of the Apex prediction logic unchanged. The same 10% blend also took Lucas Boesen’s v3 from 0.549 to 0.551. I’ve made the notebook⁠ and adapter public with the code and credits if anyone wants to try it.
