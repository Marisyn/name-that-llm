## Content

I measured what each part of a public ensemble is worth on the public LB. I took a scored base, set one part's weight to 0 (or removed the part), and submitted it as a light commit. I did this on two bases:

- **Base A: v21c, 0.638.** A fork of the nlm-v27 line.
- **Base B: v28, 0.659.** A fork of the public 0.664 notebook, with Llama 3.1 from metaresearch.

Every number below is a public LB score. "Δ" means the change from the base it was measured on.

### Removal deltas on both bases

| Part removed | Base A (0.638) Δ | Base B (0.659) Δ |
|---|---|---|
| Qwen3-14B member | −0.020 (plain head + twin) | −0.010 (plain head, twin and Gaussian head) |
| Centred twins | −0.017 (both twins) | −0.006 (`adapt_w=0`: twins, Gaussian head and test clustering off) |
| Complementary frozen stack | −0.008 | −0.004 |
| n-gram SVC | −0.011 | −0.001 |
| ATLAS | −0.009 (10% mix) | +0.001 (20% mix) |
| Sinkhorn | −0.002 (off) | see below |

On Base A, every removal lowered the score. On Base B, removing SVC or ATLAS changed the score by 0.001 or less. The same part can be worth 0.01 on one base and nothing on another, so I re-measure after switching forks instead of reusing old numbers.

The two columns don't match exactly. On Base B, the Qwen3 and twin rows also turn off the Gaussian head, and ATLAS has a different mix weight.

### Sinkhorn and typography on Base B

| Change | LB | Δ |
|---|---|---|
| Sinkhorn 0.60 → 0.45 | 0.662 | +0.003 |
| Sinkhorn 0.60 → 0.30 | 0.662 | +0.003 |
| Typography factor 1.2 → 1.5 | 0.658 | −0.001 |
| Both (0.30 and 1.5) | 0.663 | +0.004 |

**Rescoring noise:** I resubmitted v28 unchanged (same kernel version), and it scored 0.659 again. On Base A, two identical runs also scored the same (0.617 and 0.617). So in my runs, a delta of 0.001 or more came from the change, not from rescoring.

**Pitfall when forking:** `kaggle kernels pull` gets the notebook's latest version, not the version that was scored. The 0.664 notebook's scored version 2 used Sinkhorn 0.30 and typography 1.5. My pull had 0.60 and 1.2. That difference alone was 0.659 vs 0.663.

**Adding is not the reverse of removing:** On a 0.642 base (nlm-v27 without Llama), I added a ModernBERT-large member.

- At weight 1.5, it scored 0.638.
- At 0.5, it scored 0.641.
- At 0.3, it scored 0.642.

A lower weight only brought the score back to the base. None of the weights went above it.

**Cost:** each ablation is a light commit, which uses a few minutes of GPU. The scoring rerun doesn't use GPU quota.
