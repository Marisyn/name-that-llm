I've mostly run non-LLM methods so far. Short answer: yes, they get past 0.5, but on my runs they flatten out around 0.60–0.62. All numbers are balanced accuracy: OOF is cross-validation with prompts split across folds, LB is the public leaderboard.

Intrinsic watermarks: typography nearly identifies the model family. Gemini almost never uses em-dashes, Claude and GLM use em-dashes but never curly quotes, and GPT uses curly quotes. Getting the family right is easy (87–99%). Telling versions apart within a family is the hard part (67–76%). Keep the raw characters, and don't normalise punctuation.

What I got:

Aapproach	OOF	LB
1. TF-IDF + logistic regression	0.31	0.32
2. + external data + class weights	0.46	0.40
3. + stylometric features stacked with XGBoost	0.49	0.43
4. DeBERTa-v3-large	0.50	–
5. ModernBERT-large	0.55	0.55
6. UltraBERT-380M, on 241k external rows	0.60	–
7. Equal blend of encoders + TF-IDF stack	0.625	0.616
