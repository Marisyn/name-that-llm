## Content

Telling Claude vs Chat GPT is obvious, telling Sol vs Terra can be a pain. Yet, solution that get's model's family correctly every time can score 0 if it's not able to reliably tell particular model. This might be a little bit frustrating and may give impression when looking only at leaderboard scores, that telling what family wrote the response is harder that it actually is. Also current metric may skew public solutions towards giveing better scores for model families that don't have a lot of participating models (Qwen, GLM, Kimi), and worse scores for families with a lot of models (GPT, Claude, Gemini), which can create another false impression that texts generated by Open AI, Gemini or Claude models are harder to detect.


Having something in the metric that rewards correct model's family prediction can be beneficial.
