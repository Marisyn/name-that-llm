Yes, the Overview line already answers the test-side question. On train, 149 of 150 prompts have 18 answers and one prompt has 17 (claude-fable-5 is the short model). That can make train look like neat rounds. Public and private do not promise a full 18-model group, and model counts are unequal, so anything that forces one of each label per prompt on test is fitting a structure the test set does not have.
