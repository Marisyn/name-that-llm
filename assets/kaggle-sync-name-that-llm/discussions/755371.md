## Content

Hi all,

Train has only 150 prompts, so generating extra passages via the models' APIs looks tempting. But we don't know the original setup (system prompt, temperature, length control, post-processing). Data generated under a different setup might teach the model our prompt template instead of the model's style.

So, what do you think:
- Has anyone tried it? Did CV and LB improve?
- Any tricks to match the original style (e.g. few-shot with train passages)?
- Would it be safer to use extra data only for pre-training and then fine-tune on competition data?

Would love to hear your experience!
