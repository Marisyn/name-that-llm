Rather than treating the dataset as raw text chunks, this notebook approaches authorship attribution through the lens of **Forensic Stylometry**: separating what the model *writes about* (the prompt topic) from *how the model writes* (its stylistic and orthographic habits).

---

### Key Findings & Visual Investigations (Part I)

The notebook includes 9 publication-grade diagnostic plots (using a custom high-contrast dark/teal palette):

1. **Class Balance & Lab Families**: Horizontal breakdowns showing response counts across the 6 major foundation labs (GPT, Claude, Gemini, GLM, Qwen, Kimi).
2. **The Prompt-by-Model Matrix**: A 150 × 18 cross-tabulation heatmap proving experimental completeness (149 of 150 prompts were answered by all 18 models).
3. **Raw Length vs Within-Prompt Residuals**: Isolating intrinsic model verbosity from prompt difficulty using prompt-centered residuals (L - mean_prompt).
4. **Punctuation Fingerprints & Cohen’s d**: Measuring orthographic invariants (spaced em-dashes ' — ', curly apostrophes '’', bare em-dashes '—', semicolons, colons) and their prompt-centered effect sizes.
5. **The Lineup (18 Voices, 1 Prompt)**: A side-by-side textual excerpt comparison of multiple model families responding to an identical philosophical prompt.
6. **Prompt-Grouped CV vs Random CV Confusion Matrix**: Visual proof that standard random splits leak prompt content, and that **within-family sibling ambiguity accounts for over 65% of all residual errors**.

### The End-to-End Inference Engine (Part II)

The backend provides a complete, fast-committing (11.5 minutes) inference pipeline designed to run cleanly within the 9-hour submission limit:

* **Multi-Scale Neural Transformer Core**: Combining 9 transformer backbones (Qwen3 14B/8B/4B, Qwen2.5 14B/7B, Llama-3.1 8B, DeBERTa, ELECTRA, UltraBERT, OLMo-2) across 8 hidden representation depths.
* **224,000 Open Pool Sibling Specialists**: Asynchronous multi-gram character and word TF-IDF SGD classifiers trained on clean external passages (crtproduction/name-that-llm-open-pool) to resolve Gemini, GPT, and Claude sibling confusion using Bayesian probability mass conservation.
* **25-Segment Native GLM Likelihood Pipeline**: Offline evaluation with ntl-bin over the GGUF segment mirror to directly arbitrate the most frequent confusion pair (glm-5.3 vs glm-5.3-flash).
* **2D-Swept Sinkhorn Class Balancing**: Implements Dirichlet prior calibration (w = 0.45, rho = 0.35) to handle skewed class distributions.
* **Reciprocal Prompt-Pair Balancing**: TF-IDF cosine similarity neighbor clustering with duplicate author probability mass dissipation.
* **Calibrated Soft Typography Invariant Filtering**: Soft multiplicative veto (penalty = 0.15) that bounds maximum cross-entropy loss and eliminates infinite-loss penalties on quotation passages.
