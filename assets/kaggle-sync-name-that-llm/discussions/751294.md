 Hi! Rule 2.6 allows external data if it is publicly available to all participants at no cost, or if the host considers it reasonably accessible at minimal cost.

 We would like to build a small extra training set by generating text with some of the 18 listed models through a paid API (OpenRouter). Details:
 - The prompts are written by us from scratch. No competition text (train or test) is sent to any service.
 - Total cost is around US$2.
 - We would publish the resulting dataset publicly on Kaggle before using it in any submission, so every participant can use it.
 - We would also check each provider's terms of use before publishing.

 Would you consider this acceptable under rule 2.6? Or is paid-API generation not acceptable regardless of cost or publication? Thanks!
