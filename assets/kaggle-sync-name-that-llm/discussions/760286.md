## Content

Most public notebooks here sit at 0.68-0.78, and nearly all of them need a GPU plus model inference. If you are on CPU — or you just want a starting point whose leaderboard number you can trust — the useful question is different: what does a pure feature-based baseline actually score, and why can't it go higher?

I tried to answer that with measurements rather than guesses.

**1. The CV protocol decides everything.** Identical word+char TF-IDF with a logistic regression:
- StratifiedKFold: **0.09**
- GroupKFold(prompt_id): **0.32**

The hidden test uses prompts never seen in training, so only the grouped split is honest.

**2. CV to LB calibration.** Tuned CPU pipeline (char_wb + 26 style features computed from the text + LinearSVC):
- GroupKFold CV: **0.3515**
- actual public LB: **0.339** (gap 0.013)

The protocol transfers, so the number means something.

**3. Ablations** (same folds, same protocol):

| Configuration | BA |
|---|---|
| word-only TF-IDF + LinearSVC | 0.221 |
| char-only (3,5) + LinearSVC | 0.275 |
| ComplementNB | 0.244 |
| soft-vote ensemble (LR+SVC+NB) | 0.278 |
| word+char(3,5) + LR C=2 | 0.3197 |
| **char_wb(2,5) + style x0.3 + LinearSVC** | **0.3515** |
| style x0.5 | 0.348 |
| word(1,3)+char_wb, 100k features | 0.276 |

More features is worse here: with 2,699 rows the vocabulary drowns.

**4. Where the errors actually go** (the part I did not expect): about **48%** of off-diagonal errors stay inside a model family. gemini-3.8-flash leaks **36%** of its own samples into gemini-3.7-flash; gpt-5.6-sol to luna 19%; glm-5.3 to claude-opus-5 20%. And claude-fable-5 has **6% recall**. The label is a *version* label, not a style label.

**5. A negative result worth sharing:** routing family-first and then model-within-family is *worse* — 0.333 against 0.348 flat. The family head compounds its own errors (family-level BA is only 0.555), so the router loses more than the specialists gain.

**Conclusion:** n-gram features top out around 0.35. The jump to 0.70 is not tuning, it is likelihood scoring — the probability each model assigns to the text. Everything in the 0.68+ tier pays for that in GPU hours.
