## Content

Hello Name That LLM organizers,

I'm running a local attribution experiment and want to validate it on independent prompts without using hidden-test labels or reusing my consumed local confirmation set. I have seen the existing questions about external data and generation settings; this request focuses on matching the model versions and collection policy.

Could you point me to organizer-approved public documentation covering:

1. The exact model IDs, snapshots, serving providers and generation dates behind each of the 18 labels.
2. The system instructions, sampling settings, reasoning effort, output limits, tool/context policy, and any extraction or editing applied to the final passages.
3. Any additional labeled responses from prompts outside the existing 150 training prompts and outside the hidden test. A useful independent panel would cover at least 30 new prompts across all 18 models.
4. If no additional data exists, a supported way to obtain outputs from matching model versions, and the applicable conditions for collecting and using them for local research or later competition work.

I also reviewed the public Name That LLM: Response Corpus:
https://www.kaggle.com/datasets/olegzholobov/name-that-llm-response-corpus

Its complete 18-model groups come from SpeechMap, with some reasoning/non-reasoning variants and dated returned IDs. Can you provide the competition's version/settings documentation so participants can assess whether those outputs are comparable? I have not evaluated my candidate on that corpus.

One specific concern is Gemini 3.7 Flash: Google's developer API documentation says that requests to gemini-3.7-flash are redirected to gemini-3.8-flash, while Google Cloud documents a separate 3.7 offering. Qwen's documentation also lists an upgraded 0902 snapshot. I'd like to avoid treating successor or mismatched-snapshot outputs as the original labels.

I'm not requesting hidden-test examples, labels, or privileged scoring information. Links to information or data available under the competition's approved access conditions would be sufficient.

Thank you.
