Check general.architecture in the GGUF with gguf-py, and attach a newer llama.cpp build as a dataset; the preinstalled one is likely too old. Per-passage mmap inference won't fit 9h for a model that size: prefill touches most experts, so you stream most of the model each passage. The workable route is layer streaming over the whole test set: load one layer, run all passages' hidden states through it, free it, next layer. That reads the weights once. 128–256 tokens is usually enough for log-prob stats. Measure the curve on a train subset, and remember the feature has to exist for train rows too. I'd try GLM-5.3-Flash first, since it's smaller and targets the glm-5.3 vs Flash split directly.
