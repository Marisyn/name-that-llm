## Content

Hi everyone! I'm working on a relatively lightweight approach and would appreciate ideas for the next useful experiment.

What I've tried

- Character/word TF-IDF with linear classifiers and simple writing-style features. The earlier TF-IDF models reached 0.331 on the public leaderboard; a joint-feature SVM reached 0.348.
- A fixed rank-based blend of the sparse classifier and an Ettin 68M encoder reached 0.375 public score.
- Lowercasing the word features while retaining punctuation-aware tokenization reached 0.377 in that blended pipeline.
- My latest blend adds positional style and lexical views. It combines a global sparse/style head (40%), a positional sparse/style head (40%), and the existing Ettin model (20%), using per-row class ranks. This submitted version scored 0.383 publicly.

Validation and what the numbers do not show

I use prompt-grouped 5-fold validation and balanced accuracy. The earlier positional-style blend, before adding positional lexical views, had OOF balanced accuracy 0.403753. Adding word n-gram views of the first and last 512 characters gave 0.404867: only 3 extra correct predictions overall, with 3 of 5 folds improving. A paired bootstrap over prompts gave a difference interval that includes zero.

All 150 training prompts have already been used during development, so I treat these OOF results as exploratory rather than an untouched confirmation set. The positional-style-only comparator has not received an official score yet. Consequently, the 0.377 to 0.383 public improvement does not isolate the effect of the positional lexical features alone.

I also tried several encoder-training variations, including LoRA/DoRA, weight averaging, partial-layer training, and style-oriented auxiliary training. Those particular experiments did not give a convincing improvement over my existing blend on the development splits. I don't take that as evidence that those methods cannot work here.

What I'm considering next

1. Measure the frozen positional-style comparator on the official evaluation, to better understand the latest change before adding more components.
2. Compare binary word occurrence with frequency-based TF-IDF while keeping the rest fixed. This comparison has no completed result yet.
3. Look for a genuinely complementary representation rather than repeatedly tuning blend weights on the same validation prompts. I'd like to keep offline inference practical and avoid assuming that hidden-test rows form complete 18-model prompt groups.

For people working on similar approaches:

- Would you prioritize a stronger encoder, model-likelihood features, or more careful sparse/stylometric features from this point?
- What validation checks have helped you distinguish model style from prompt/topic leakage, especially after reusing the same small set of prompts?
- Are there useful public notebooks or papers for a small, controlled next experiment? Negative results or pitfalls would be helpful too.

Thanks! I'm sharing aggregate results and methods here, not test predictions or individual dataset examples.
