## data-description

The dataset consists of self-contained paragraphs generated by 18 language models across diverse topics. Every passage is an authentic LLM completion. Only light formatting cleanup was applied (for example, removing a `**bold**` wrapper around a whole passage).

## Files

* **train.csv** — The training set: 2,699 passages written for 150 prompts.
* **test.csv** — The test set: three example rows during interactive sessions, just so your code runs; ~4000 passages in the hidden rerun. Test passages are written for prompts that do not appear in **train.csv**.
* **sample_submission.parquet** — A sample submission in the correct format: one row per `id` in **test.csv**, with columns `id` and `model`.

## Columns

### **train.csv**
* `id` *(str)*: Unique anonymised identifier for the passage.
* `prompt_id` *(str)*: Anonymised identifier of the prompt the passage answers.
* `text` *(str)*: The generated text passage.
* `model` *(str)*: The ground-truth model name (one of the 18 candidate models).

### **test.csv**
* `id` *(str)*: Unique anonymised identifier for the passage.
* `text` *(str)*: The unlabelled text passage to classify.

### **sample_submission.parquet**
* `id` *(str)*: Matches `id` in **test.csv**.
* `model` *(str)*: Your predicted model name (e.g. `gpt-5.5`).
